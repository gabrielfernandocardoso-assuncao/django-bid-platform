# django-bid-platform
### Programa de Leilões ###
Como funciona: 
    Um sistema onde usuários cadastram itens para leilão com um preço inicial e uma data/hora limite. Outros usuários podem dar lances. O sistema precisa validar se o novo lance é maior que o anterior e fechar o leilão automaticamente (ou via validação de requisição) quando o prazo expirar, mostrando quem foi o arrematante.
